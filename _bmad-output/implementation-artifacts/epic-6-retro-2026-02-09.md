# Epic 6 Retrospective (2026-02-09)

## Scope Reviewed
- Story 6.1: Remove hardcoded AOS controls
- Story 6.2: File-first per-ticker prefill
- Story 6.3: Persist-and-run consistency

## What Went Well
- Removed UI assumptions that were causing hidden behavioral drift.
- Configuration flow is now explicit: file -> FE prefill -> edit -> save -> run apply.
- Existing API contracts were sufficient; no endpoint expansion required.

## What Was Challenging
- Legacy default injection in FE created implicit behavior (hour filter) that was not obvious to user.
- Ensuring new UX remains simple while preserving full ticker-level flexibility.

## Key Learnings
- Strategy behavior-critical defaults should live in versioned config, not UI heuristics.
- File-driven prefill plus explicit save semantics improves reproducibility.

## Action Items
- Keep AOS UI free of hardcoded profitability guidance.
- Add targeted smoke checks for bar-count deltas when config filters change.
